# Architecture Overview

## js
The js folder contains the main game initialization, input handling and UI logic.

## Models
Contains all game objects such as player, enemies, world logic and HUD elements.

## Levels
Defines the structure and content of game levels.

## Assets
All static files such as images, fonts and audio are stored in the assets directory.

## Refactoring
The project was refactored to improve maintainability, structure and readability.
