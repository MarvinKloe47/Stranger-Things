# City Fighters

City Fighters is a browser-based 2D canvas fighting game built with HTML, CSS and JavaScript.

## Features
- side-scrolling gameplay
- enemy and boss encounters
- coin collection system
- shop and unlockable abilities
- mobile touch controls
- audio support
- win and lose screens

## Technologies
- HTML5
- CSS3
- JavaScript
- Canvas API

## Project Status
The project was initially created as a functional prototype and was later refactored to improve structure, naming, maintainability and documentation.

## Run locally
Start the project with a local development server, for example using the VS Code Live Server extension.
